# Training App

A small React Native app for keeping track of training habits.

## Getting started

Use Node.js 20.18 or newer, then install dependencies and start Expo:

```bash
npm install
npm start
```

Use `npm run android`, `npm run ios`, or `npm run web` to launch a specific
target. The starter screen currently includes weekly progress, recent sessions,
and a placeholder action for logging a new session.
